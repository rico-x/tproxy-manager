## Изменения / Changes

### Русский

Добавлен удобный механизм делиться ссылками proxy с устройствами в сети роутера. Теперь роутер может публиковать итоговый список VLESS-ссылок Watchdog как подписку, чтобы использовать эти ссылки на телефоне, ПК или другом клиенте без ручного копирования из интерфейса роутера.

- Добавлен блок `Расшаривание подписки` на вкладке Watchdog после списка VLESS-ссылок.
- Добавлены две универсальные подписки: `plain` и `base64`.
- Добавлен режим выбора ссылок для экспорта: все ссылки или только отмеченные строки.
- В таблицу VLESS-ссылок добавлен столбец `В подписке` для выборочного экспорта.
- Добавлены публичные endpoint подписок:
  - `/cgi-bin/luci/tproxy-manager/subscription/plain`
  - `/cgi-bin/luci/tproxy-manager/subscription/base64`
- Добавлен профиль настроек `/etc/tproxy-manager/watchdog-share.json`.
- В документацию добавлено описание рекомендуемых форматов: `base64` для v2RayTun, Shadowrocket, v2Box и V2rayNG; `plain` для Happ и клиентов с raw VLESS list.
- Обновлены русские переводы интерфейса.

### English

Added a convenient mechanism for sharing proxy links with devices on the router network. The router can now publish the final Watchdog VLESS list as a subscription, so phones, PCs, and other clients can use the links without manually copying them from the router UI.

- Added the `Shared router subscription` block on the Watchdog tab after the VLESS link list.
- Added two universal subscription formats: `plain` and `base64`.
- Added export selection mode: all links or only selected rows.
- Added the `Shared` column to the VLESS table for selective export.
- Added public subscription endpoints:
  - `/cgi-bin/luci/tproxy-manager/subscription/plain`
  - `/cgi-bin/luci/tproxy-manager/subscription/base64`
- Added the settings profile `/etc/tproxy-manager/watchdog-share.json`.
- Updated documentation with recommended formats: `base64` for v2RayTun, Shadowrocket, v2Box, and V2rayNG; `plain` for Happ and clients that accept raw VLESS lists.
- Updated Russian UI translations.
