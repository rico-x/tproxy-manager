## Изменения / Changes

### Русский

Исправление сбоя при восстановлении бэкапа.

- Страница восстановления падала с `Runtime error`, если в бэкапе есть настройка, добавленная или удалённая относительно текущей конфигурации. Diff с одними лишь изменёнными значениями отображался нормально, поэтому сбой проявлялся не на всяком архиве.
- Та же причина затрагивала сообщение о неверном имени интерфейса при сохранении настроек TPROXY.

### English

Fixes a crash in backup restore.

- The restore page failed with `Runtime error` when the backup contained a setting added or removed relative to the current configuration. A diff with only changed values rendered fine, so the crash did not show up on every archive.
- The same cause affected the invalid-interface-name message when saving TPROXY settings.
