## Изменения / Changes

### Русский

Релиз о надёжности и безопасности: закрыта утечка расшаренной подписки, устранены атаки через временные файлы, сохранения стали транзакционными.

**⚠️ Важно при обновлении**

- Расшаренная подписка больше не отдаётся без токена. Раньше в конфигурациях без настройки `Режим доступа` список proxy мог скачать любой, кто знал URL. Установка сама включает режим `С токеном` и создаёт токен, если его не было. **Ранее разосланные ссылки без токена перестанут работать** — раздайте их заново из блока `Расшаривание подписки`.

**Безопасность**

- Критично: расшаренная подписка отдавала список proxy без проверки токена.
- Устранены symlink-атаки через предсказуемые временные файлы: локальный пользователь мог заставить роутер записать свои данные в чужой файл. Затронуты TPROXY, обновление GEO-баз и расшифровка Happ-ссылок.
- Подписка, отвечающая gzip-бомбой, больше не загружает процессор роутера: распаковка ограничена по объёму.
- Раздача raw capture соблюдает срок жизни токена и больше не отвечает после его истечения.

**Надёжность**

- Сохранения стали транзакционными: операция, затрагивающая несколько файлов, сначала снимает копию, а при сбое возвращает прежнее состояние или честно сообщает, что не смогла.
- Если операцию оборвали посреди записи (перезагрузка, потеря питания), на вкладке `TPROXY` появляется предупреждение с возможностью восстановить прежнее состояние.
- Одновременные `start`/`stop`/`restart` больше не мешают друг другу и не оставляют правила в перемешанном состоянии.
- Смена nft-таблицы, fwmark или таблиц маршрутизации корректно убирает объекты предыдущего запуска; выключение IPv6 убирает v6-правила.
- Списки перестали принимать значения, которые затем молча отбрасывались, — например `::::` или диапазон портов `100-50`.
- Интерфейс больше не сообщает об успехе там, где действие не выполнилось: рестарт TPROXY, переключение ядра, сохранение настроек, операции с GEO и очистка журналов показывают фактический результат.

### English

A reliability and security release: closes a leak of the shared subscription, removes temporary-file attacks, and makes saves transactional.

**⚠️ Upgrade notice**

- The shared subscription is no longer served without a token. Previously, in configurations without the `Access mode` setting, anyone who knew the URL could download the proxy list. The installer switches sharing to `Token` mode and creates a token if there was none. **Links handed out earlier without a token stop working** - re-share them from the `Shared router subscription` block.

**Security**

- Critical: the shared subscription served the proxy list without checking the token.
- Removed symlink attacks through predictable temporary files, where a local user could make the router write data into someone else's file. Affected TPROXY, GEO database updates, and Happ link decryption.
- A subscription answering with a gzip bomb no longer pins the router's CPU: decompression is size-capped.
- Raw capture honours its token lifetime and stops answering once it expires.

**Reliability**

- Saves are transactional: an operation touching several files copies them first, and on failure either restores the previous state or says plainly that it could not.
- If an operation is cut short mid-write (reboot, power cut), the `TPROXY` tab shows a warning offering to restore the previous state.
- Concurrent `start`/`stop`/`restart` no longer interfere with each other or leave rules in a mixed state.
- Changing the nft table, fwmarks or route tables now removes the previous run's objects; disabling IPv6 removes the v6 rules.
- Lists no longer accept values that were silently dropped afterwards - for example `::::` or the port range `100-50`.
- The UI no longer reports success where nothing happened: TPROXY restart, engine switching, settings saves, GEO operations and log clearing all show the actual result.
