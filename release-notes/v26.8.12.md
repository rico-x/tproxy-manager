## Изменения / Changes

### Русский

Релиз исправлений маршрутизации Mihomo, автозапуска ядер и внешнего вида страниц.

**Важное**

- Mihomo не отправлял трафик через прокси. Генерируемый конфиг содержал `mode: global`, а в этом режиме mihomo полностью игнорирует `rules` и ходит через встроенный селектор GLOBAL, по умолчанию — DIRECT. Все управляемые правила не работали, а проверка ссылок измеряла прямое соединение: на одном и том же списке Mihomo давал 2 живые ссылки из 63 против 43 из 53 у Xray. Теперь генерируется `mode: rule` — 42 из 53 на том же списке.
- Уже установленный конфиг при обновлении сохраняется, поэтому пользователи прежних версий остались бы на сломанном режиме. Добавлена миграция: правится только верхнеуровневый ключ и только в конфигах с сигнатурой пакета, с сохранением датированной копии.
- Конфиг, который пакет не генерировал, больше не заменяется без копии. Рукописный `/etc/mihomo/tproxy-manager.yaml` мог быть заменён сгенерированным при первом же применении ссылки — `mv` шёл без копии, и вернуть содержимое было нельзя. Теперь перед заменой чужой конфиг копируется в `<конфиг>.pre-managed`, один раз, и то же сделано для sing-box. Копия снимается только когда замена действительно произойдёт (после генерации и проверки), и снимается обратно, если применение не удалось.
- В автозапуске остаётся ровно одно ядро. Переключение останавливало остальные ядра, но оставляло их в автозагрузке, и после перезагрузки два ядра боролись за TPROXY-порт — кто победил, тот и определял маршрутизацию. Автозапуск теперь переключается только после подтверждённого запуска нового ядра, а неудачное переключение возвращает автозапуск тому ядру, которое действительно работает.
- Вкладка `TPROXY` сообщает о конфликте автозапуска, доставшемся от прежних версий или сделанном вручную, и предлагает исправить его одной кнопкой.

**Исправления**

- Профиль ядра больше не может быть перезаписан значениями другого ядра, если `proxy_engine` разошёлся с остальными настройками (такое возможно, когда `proxy_engine` меняют сторонним скриптом).
- Статус ядра больше не выводит одновременно «ACTIVE» и «установлен · остановлен · выключено» — теперь одно состояние.
- Кнопка `.small-btn` на вкладке обновлений не применяла свой стиль: CSS-комментарий закрывался раньше времени и «съедал» правило. Добавлена проверка, которая не даёт этому повториться.
- Страница загрузки файла отдавала 500 из-за литерального `%` в шаблоне форматирования.

**Настройки**

- Путь к init-скрипту каждого ядра можно изменить — для роутеров, где ядро запускается своим скриптом.

**Интерфейс**

- Все страницы переведены на переменные темы вместо собственных жёстко заданных цветов, с отдельным блоком для тёмной темы. Контраст статусов на подложке был 1.75:1 и 1.76:1 — стало 7.4 и 7.59 в тёмной теме, 9.51 и 10.37 в светлой.
- Широкие таблицы прокручиваются по горизонтали внутри своей области, а на экранах уже 760px превращаются в карточки: строка watchdog стала 266px вместо 624px на мобильном.
- Watchdog: счётчики над таблицей, ссылки сокращены до трёх строк и раскрываются при наведении, значения больше не разрываются посередине — «745 ms», дата и время исключения остаются целыми.
- Блок активного ядра свёрнут: редактор пути открывается по клику.

### English

A release fixing Mihomo routing, engine autostart and the appearance of every page.

**Important**

- Mihomo sent nothing through the proxy. The generated config carried `mode: global`, and in that mode mihomo ignores `rules` entirely and routes through the built-in GLOBAL selector, which defaults to DIRECT. Every managed rule was dead and link checks measured direct connectivity: on the same link list Mihomo reported 2 alive of 63 against Xray's 43 of 53. The generated config now uses `mode: rule` - 42 of 53 on that same list.
- An already installed config is kept on upgrade, so users of earlier versions would have stayed on the broken mode. A migration was added: it rewrites only the top-level key, only in configs carrying this package's signature, and keeps a dated copy first.
- A config this package did not generate is no longer replaced without a copy. A hand-written `/etc/mihomo/tproxy-manager.yaml` could be replaced by the generated one on the first applied link - the `mv` had nothing behind it and the content could not be recovered. A foreign config is now copied to `<config>.pre-managed` once before being replaced, and sing-box has the same guard. The copy is taken only when a replacement is actually going to happen (after generation and validation), and released again if the apply fails.
- Exactly one engine stays in autostart. Switching stopped the other engines but left them armed for boot, so after a reboot two engines raced for the TPROXY port and the winner decided how traffic was routed. Autostart now follows the switch only once the new engine is verified up, and a failed switch restores it to the engine that is actually running.
- The `TPROXY` tab reports an autostart conflict inherited from earlier versions or made by hand, and offers to fix it in one click.

**Fixes**

- An engine profile can no longer be overwritten with another engine's values when `proxy_engine` disagrees with the rest of the settings (which happens when `proxy_engine` is changed by an external script).
- The engine status no longer prints "ACTIVE" and "installed - stopped - disabled" at the same time; it reports one state.
- The `.small-btn` button on the updates tab was not styled: a CSS comment closed early and swallowed the rule. A check was added so this cannot come back.
- The file upload page returned 500 because of a literal `%` in a formatting template.

**Settings**

- The init script path of each engine can be edited, for routers that start an engine from their own script.

**UI**

- Every page now uses the theme's variables instead of its own hardcoded colours, with a separate block for the dark theme. Status text against its tint measured 1.75:1 and 1.76:1; it is now 7.4 and 7.59 in dark and 9.51 and 10.37 in light.
- Wide tables scroll horizontally inside their own area and turn into cards below 760px: a watchdog row is 266px instead of 624px on mobile.
- Watchdog: counters above the table, links clamped to three lines and expanded on hover, and values no longer break mid-unit - "745 ms" and a cooldown's date and time each stay together.
- The active-engine block is folded away; the path editor opens on click.
