## Changelog v26.8.13

### Русский

#### Новое

- Проверка ссылок теперь выполняется выбранным ядром: Xray, Mihomo или sing-box.
- Пакетная проверка работает на всех трёх ядрах.
- Добавлен статус `Не поддерживается` для ссылок, транспорт которых не поддерживает активное ядро.
- Добавлена единая фрагментная структура конфигурации Mihomo и sing-box.

#### Outbound-шаблоны

- В интерфейсе доступны шесть шаблонов: VLESS и Hysteria 2 для каждого ядра.
- Служебные шаблоны одиночной и пакетной проверки убраны из формы.
- Пользовательские изменения outbound-шаблонов применяются в рабочем конфиге, одиночной и пакетной проверке.

#### Исправления

- Применение конфигурации стало транзакционным с проверкой и автоматическим откатом при ошибке.
- Исправлены преждевременные откаты при медленном запуске ядра и конфликты занятых портов.
- Исправлена синхронизация активного ядра, его сервиса и автозапуска.
- Устранено использование команды проверки от другого ядра.
- Сохранение настроек Watchdog больше не повреждает профиль активного ядра.
- Mihomo корректно обрабатывает одинаковые имена прокси и специальные символы в названиях.
- Исправлены генерация Mihomo в режиме `rule` и передача `allowInsecure`.
- Исправлена подстановка плейсхолдеров в шаблоне Hysteria 2.

### English

#### New

- Links are now checked by the selected engine: Xray, Mihomo, or sing-box.
- Batch checks now work with all three engines.
- Added an `Unsupported` status for links whose transport is not supported by the active engine.
- Added a unified fragment-based configuration layout for Mihomo and sing-box.

#### Outbound templates

- The UI now provides six templates: VLESS and Hysteria 2 for each engine.
- Internal single-check and batch-check templates were removed from the form.
- User changes to outbound templates are applied to the live configuration, single checks, and batch checks.

#### Fixes

- Configuration changes are now transactional, including validation and automatic rollback on failure.
- Fixed premature rollbacks during slow engine startup and conflicts caused by ports that were still occupied.
- Fixed synchronization of the active engine, its service, and autostart state.
- Prevented a check command belonging to another engine from being used.
- Saving Watchdog settings no longer corrupts the active engine profile.
- Mihomo now handles duplicate proxy names and special characters in names correctly.
- Fixed Mihomo generation in `rule` mode and `allowInsecure` propagation.
- Fixed placeholder substitution in the Hysteria 2 template.
