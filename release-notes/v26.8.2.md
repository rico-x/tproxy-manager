## Изменения / Changes

### Русский

Добавлена поддержка Hysteria 2 через Xray в существующий Watchdog без изменения основного пользовательского сценария.

- Watchdog теперь работает с `vless://`, `hysteria2://` и `hy2://` в едином списке proxy-ссылок.
- Конвертер `/usr/bin/vless2json.sh` расширен до protocol-aware режима: VLESS и HY2 рендерятся через разные шаблоны.
- Добавлены отдельные HY2-шаблоны outbound, test-instance и batch-check.
- Batch-проверка теперь группирует ссылки по протоколу и автоматически выбирает нужный test-template.
- В таблице ссылок добавлен бейдж протокола `VLESS` / `HY2`.
- Подписки Happ/raw/base64/JSON теперь извлекают не только VLESS, но и Hysteria outbounds.
- Расшаривание подписки теперь экспортирует общий список proxy-ссылок, включая HY2.
- Во вкладку XRAY добавлен блок версии Xray: текущая версия, latest stable, asset под архитектуру, обновление и откат.
- Добавлен helper `/usr/bin/tproxy-manager-xray-version.lua` для установки/отката Xray с проверкой `SHA2-256`.
- Добавлена зависимость `unzip` для обновления Xray из официальных архивов.
- Исправлено определение активной ссылки/подписки для HY2, чтобы статус не показывал неверный сервер.
- Улучшен редактор Watchdog-шаблонов: выбор VLESS/HY2 шаблонов в одном списке, без лишних заголовков.
- Исправлена JSONC-валидация шаблонов с плейсхолдерами `__OUTBOUNDS__`, `__BATCH_RULES__`, `__TEST_PORT__` и аналогами.
- Обновлены русская и английская документация, а также строки локализации интерфейса.

### English

Added Hysteria 2 support through Xray in the existing Watchdog flow without changing the main user workflow.

- Watchdog now supports `vless://`, `hysteria2://`, and `hy2://` in one unified proxy link list.
- `/usr/bin/vless2json.sh` is now protocol-aware: VLESS and HY2 are rendered through separate templates.
- Added dedicated HY2 outbound, test-instance, and batch-check templates.
- Batch checks now group links by protocol and automatically select the matching test template.
- Added a compact `VLESS` / `HY2` protocol badge to the link table.
- Happ/raw/base64/JSON subscriptions now extract Hysteria outbounds in addition to VLESS.
- Shared router subscriptions now export the unified proxy link list, including HY2 links.
- Added an Xray version block to the XRAY tab: current version, latest stable release, architecture asset, update, and rollback.
- Added `/usr/bin/tproxy-manager-xray-version.lua` for Xray install/rollback with `SHA2-256` verification.
- Added the `unzip` dependency for updating Xray from official release archives.
- Fixed active HY2 link/subscription detection so the status block does not show the wrong server.
- Improved the Watchdog template editor with one selector for VLESS/HY2 templates and fewer duplicate headings.
- Fixed JSONC validation for templates with placeholders such as `__OUTBOUNDS__`, `__BATCH_RULES__`, `__TEST_PORT__`, and related values.
- Updated Russian and English documentation and UI localization strings.
