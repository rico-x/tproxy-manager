## Изменения / Changes

### Русский

Добавлено sing-box как третье поддерживаемое proxy-ядро, устранён ряд уязвимостей в веб-интерфейсе и firewall-скрипте, доработан UX редакторов и усилена безопасность CI-пайплайна сборки.

**Новое: sing-box**
- sing-box добавлен как третье управляемое proxy-ядро наравне с Xray и Mihomo: отдельная вкладка с JSON-редактором, менеджер версий с откатом, конвертер ссылок `proxy2singbox.lua`, поддержка в Watchdog (одиночные и batch-проверки).
- Переключение ядра — единый селектор «Активное proxy-ядро» на вкладке TPROXY вместо отдельных чекбоксов включения модулей; неактивные демоны останавливаются автоматически, чтобы не конфликтовать по портам.
- Общий реестр ядер (`engines.lua`) и общий модуль управления версиями (`core_version.lua`) — переиспользуются Mihomo и sing-box.

**Безопасность**
- Критический баг: опечатка (кириллическая буква вместо `e` в `sed`) ломала пересборку nft-таблицы при `restart` — трафик мог идти мимо прокси необнаруженно. Исправлено.
- Добавлена валидация формата IPv4/IPv6/CIDR для bypass- и src-списков перед вставкой в nft-конфиг.
- Закрыт SSRF/LFI и shell-инъекция в GEO-обновлениях: URL теперь только `http(s)://`, dest — абсолютный путь без `..`, генерируемый cron-скрипт использует безопасное экранирование.
- Закрыт path traversal при удалении конфигов в редакторах Xray/Mihomo/sing-box и при сохранении списков в TPROXY/Watchdog (whitelist разрешённых путей).
- Xray-конфиг теперь проверяется (`xray -test`) перед restart сервиса — как уже было у Mihomo/sing-box.
- Исправлены падения `vless2json.sh` на `%` в данных подписки и порча TSV табами в парсере ссылок Watchdog.
- `proxy2mihomo.lua` теперь учитывает `allowInsecure` для VLESS; `proxy2singbox.lua` больше не обрывает генерацию конфига из-за одной неподдерживаемой ссылки в подписке.
- Constant-time сравнение токена для эндпоинта `happ_capture`.
- CI: `usign` и `ipkg-build` зафиксированы на конкретный коммит с проверкой sha256, `alpine:edge` заменён на pinned digest, права workflow сужены до `contents: read`, экшены GitHub Actions запинены на SHA, приватные ключи подписи затираются после использования.

**UX и интерфейс**
- Устранено дублирование баннера ошибки/успеха на нескольких вкладках.
- Предупреждение о несохранённых изменениях теперь защищает и кнопки быстрого добавления (DHCP), и «Создать»/«Удалить» в JSON/YAML-редакторах, а не только переключение файла.
- Иконка «сохранить» заменена на «копировать» у кнопок копирования ссылок.
- Ошибка JSON теперь содержит кликабельную ссылку «перейти к ошибке», ставящую курсор на нужный символ в редакторе.
- Добавлены tooltips для обрезанных полей путей в расширенных настройках TPROXY и для селектора версии Xray.
- Лог Watchdog: повторяющиеся heartbeat-строки визуально приглушены, чтобы не тонули реальные события.
- Кнопка «Обновить версии» переименована в «Проверить обновления» — не путается с «Обновить до актуальной».
- Добавлен локальный smoke-test набор (`scripts/smoke-local.sh`) для проверки перед релизом.

### English

Added sing-box as a third supported proxy engine, fixed several security issues in the web UI and firewall script, polished editor UX, and hardened the CI build pipeline.

**New: sing-box**
- sing-box added as a third managed proxy engine alongside Xray and Mihomo: its own JSON editor tab, a version manager with rollback, a link converter (`proxy2singbox.lua`), and Watchdog support (single and batch checks).
- Engine switching is now a single "Active proxy engine" selector on the TPROXY tab instead of separate module-enable checkboxes; inactive daemons are stopped automatically to avoid port conflicts.
- Shared engine registry (`engines.lua`) and shared version-management module (`core_version.lua`), reused by both Mihomo and sing-box.

**Security**
- Critical bug: a stray Cyrillic character instead of `e` in a `sed` flag broke the nft table rebuild on `restart` — traffic could silently bypass the proxy. Fixed.
- Added IPv4/IPv6/CIDR format validation for bypass and src lists before they're embedded into the nft config.
- Closed an SSRF/LFI and shell-injection issue in GEO updates: URLs must now be `http(s)://` only, dest must be an absolute path without `..`, and the generated cron script uses safe shell escaping.
- Closed a path-traversal issue when deleting configs in the Xray/Mihomo/sing-box editors and when saving list files in TPROXY/Watchdog (allow-listed paths only).
- The Xray config is now validated (`xray -test`) before restarting the service, matching the existing Mihomo/sing-box behavior.
- Fixed `vless2json.sh` crashing on a bare `%` in subscription data, and TSV corruption from tab characters in the Watchdog link parser.
- `proxy2mihomo.lua` now honors `allowInsecure` for VLESS; `proxy2singbox.lua` no longer aborts the whole config generation because of one unsupported link in a subscription.
- Constant-time token comparison for the `happ_capture` endpoint.
- CI: `usign` and `ipkg-build` are now pinned to a specific commit with sha256 verification, `alpine:edge` replaced with a pinned digest, workflow permissions scoped down to `contents: read`, GitHub Actions pinned to commit SHAs, and signing keys are wiped after use.

**UX and interface**
- Removed duplicate error/success banners on several tabs.
- The unsaved-changes guard now also covers the DHCP quick-add buttons and "Create"/"Delete" in the JSON/YAML editors, not just the file-switcher dropdown.
- Replaced the "save" (floppy disk) icon with a "copy" icon on the link-copy buttons.
- JSON errors now include a clickable "jump to error" link that places the cursor at the exact character.
- Added tooltips for truncated path fields in TPROXY's advanced settings and for the Xray version selector.
- Watchdog log: repeated heartbeat lines are now visually de-emphasized so real events are easier to spot.
- Renamed "Refresh versions" to "Check for updates" (Russian UI) to avoid confusion with "Update to latest".
- Added a local smoke-test suite (`scripts/smoke-local.sh`) for pre-release checks.
