## Изменения / Changes

### Русский

Добавлены резервное копирование настроек и кнопка одной установки для ядер, устранён критический баг с произвольной записью файла, расширена защита от сбоев файловой системы на роутере.

**Новое**
- Backup/Restore на вкладке TPROXY: экспорт полного бэкапа (UCI, конфиги ядер, Watchdog, GEO) одним архивом, импорт с построчным diff по модулям и подтверждением перед применением.
- Кнопка «Установить» для неустановленных Mihomo/sing-box прямо на вкладке TPROXY.
- Скачивание релизов ядер теперь идёт полностью через `/tmp`: на диск роутера попадает только сам бинарник, без геобаз и лишних файлов архива.

**Безопасность и надёжность**
- Критично: закрыта возможность записи произвольного файла через редактор Mihomo (отсутствовала проверка имени файла при сохранении).
- Устранены ещё два места, где сбой файловой системы под нагрузкой (ESTALE) мог тихо потерять запись или уронить синхронизацию подписок.
- Исправлен баг во всём проекте: баннер об успешном действии иногда не показывался пользователю из-за особенности рендеринга LuCI.

### English

Added settings backup/restore and one-click engine install, fixed a critical arbitrary file-write bug, and hardened filesystem-failure handling further.

**New**
- Backup/Restore on the TPROXY tab: export a full backup (UCI, engine configs, Watchdog, GEO) as one archive, import with a per-module line diff and a confirm step before anything is applied.
- An `Install` button for uninstalled Mihomo/sing-box engines, right on the TPROXY tab.
- Engine release downloads now go entirely through `/tmp`; only the binary itself is copied to the router's disk, no GEO databases or other archive clutter.

**Security & reliability**
- Critical: closed an arbitrary file-write hole in the Mihomo config editor's save handler (missing filename validation).
- Hardened two more spots against filesystem hiccups (ESTALE) under load that could silently drop a write or break subscription sync.
- Fixed a project-wide bug where success banners sometimes never displayed to the user due to a LuCI rendering quirk.
